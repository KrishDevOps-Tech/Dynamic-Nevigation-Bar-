Dynamic NeviBar Workspace
A sleek, modern 9-Dot Bento Menu interface designed for high-end web workspaces. This project focuses on the "Bento Grid" design trend, providing a minimalist yet highly interactive user experience using core web technologies.

🌟 Overview
The NeviBar is an interactive navigation component that reimagines how users access dashboard elements. Instead of a traditional sidebar, it uses a centralized 9-dot grid that expands into a full workspace, utilizing smooth CSS transitions and a premium dark-mode aesthetic.

✨ Key Features
Bento Grid Interface: Inspired by modern UI trends seen in Apple and Microsoft products.

Interactive Workspace: Clicking the 9-dot icon triggers a dynamic layout shift to reveal dashboard items.

Premium Visuals: Includes Glassmorphism effects, deep shadows, and a refined color palette.

Fluid Animations: High-performance CSS transitions for a "lag-free" feel.

Responsive Core: Built to adapt across different screen resolutions.

Clean Code: Minimalist implementation using Vanilla JS and modern CSS Grid/Flexbox.

🛠️ Tech Stack
HTML5: Semantic structure for the workspace and menu elements.

CSS3: Advanced styling including:

Custom Properties (CSS Variables)

Flexbox & CSS Grid for the Bento layout

transition & transform for animations

JavaScript (ES6): Logic for menu toggling and state management.
